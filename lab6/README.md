# Лабораторная работа 6

Вариант 14: вычисление объёма цилиндра при отведении мыши от гиперссылки.

Откройте `index.html`. Введите радиус `2` и высоту `5`, наведите мышь на ссылку «Вычислить объём», затем отведите указатель. Результат: приблизительно `62,83185307` см³. Формула: `V = Math.PI * Math.pow(radius, 2) * height`.

Главное событие – `mouseout`. Дополнительное событие `blur` позволяет выполнить расчёт с клавиатуры при переходе со ссылки клавишей Tab. Нажатие Enter в форме не отправляет данные.

Поддерживаются десятичные точка и запятая. Пустой ввод, текст, ноль, отрицательные значения и переполнение отклоняются. После изменения исходных данных предыдущий результат удаляется. Кнопка «Очистить» сбрасывает форму.
