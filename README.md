# Лабораторные работы по Web-технологиям

## Лабораторная работа 1

- `Лабораторная работа 1/Letter/index.html` — письмо с разметкой текста.
- `Лабораторная работа 1/Planets/index.html` — таблица с данными о планетах.
- `Лабораторная работа 1/Лабораторная работа 1 — отчет.docx` — отчёт.

Для просмотра скачайте репозиторий и откройте нужный `index.html` в браузере.
Установка зависимостей и запуск сервера не требуются.

## Лабораторная работа 2

- `Лабораторная работа 2/BirdWatching/index.html` — макет сайта наблюдения за птицами.
- `Лабораторная работа 2/лабораторная_2.docx` — отчёт по пяти пунктам методички.

Для просмотра откройте `BirdWatching/index.html` в браузере. Стили и изображения
из архива находятся в папках `styles` и `images` проекта.

Методички и материалы к работам находятся в папке `лабы метоидчки`.
