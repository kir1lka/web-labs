# Лабораторные работы по Web-программированию

[Открыть меню лабораторных работ](https://hki-stroitel.ru:8443/web-labs/).

На титульных листах отчётов указаны прямые ссылки на соответствующие работы.

## Лабораторная работа 1

- `Лабораторная работа 1/Letter/index.html` — письмо с разметкой текста.
- `Лабораторная работа 1/Planets/index.html` — таблица с данными о планетах.
- `Лабораторная работа 1/лабораторная_1.docx` — отчёт.

Для просмотра скачайте репозиторий и откройте нужный `index.html` в браузере.
Установка зависимостей и запуск сервера не требуются.

## Лабораторная работа 2

- `Лабораторная работа 2/BirdWatching/index.html` — макет сайта наблюдения за птицами.
- `Лабораторная работа 2/лабораторная_2.docx` — отчёт по пяти пунктам методички.

Для просмотра откройте `BirdWatching/index.html` в браузере. Стили и изображения
из архива находятся в папках `styles` и `images` проекта.

Методички и материалы к работам находятся в папке `лабы метоидчки`.

## Лабораторная работа 3

- `Лабораторная работа 3/Airport/index.html` – сайт аэропорта по варианту 14.
- Четыре страницы: главная, рейсы, бронирование и контакты.
- `styles/home.css` оформляет главную, `styles/pages.css` – остальные страницы.
- Форма бронирования проверяет данные и показывает стоимость билетов. Это учебный пример без отправки и сохранения данных.
- `Лабораторная работа 3/лабораторная_3.docx` – отчёт.

## Лабораторная работа 4

- `Лабораторная работа 4/index.html` – таблица случайных RGB-цветов и ссылки на XML-документы.
- `timetable-internal.xml` – расписание с внутренней DTD.
- `timetable.xml` и `timetable.dtd` – расписание с внешней DTD.
- `timetable2.xml` и `timetable.xsd` – расписание с XML Schema.
- `gradeReport.xml`, `gradeReport.dtd`, `gradeReport2.xml` и `gradeReport.xsd` – экзаменационная ведомость с DTD и XSD.
- `Лабораторная работа 4/лабораторная_4.docx` – отчёт.

Работы можно открыть локально или на [сервере](https://hki-stroitel.ru:8443/web-labs/).
Файлы загружены по FTP с явным TLS. Публикация GitHub Pages отключена.
Исходники меню и конфигурация публикации находятся в папке `publish`.
После коммита и пуша обновите сайт на сервере командой:

```bash
git -C /opt/web-labs/repo pull --ff-only
```

Caddy открывает файлы прямо из репозитория. Сборка и Python не требуются.
