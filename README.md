# Лабораторные работы по Web-программированию

[Открыть лабораторные работы](https://hki-stroitel.ru:8443/web-labs/).

Главное меню – `index.html`, его оформление – `styles.css`.

| Папка | Содержание |
| --- | --- |
| `lab1/letter` | Разметка письма |
| `lab1/planets` | Таблица планет |
| `lab2` | Страница Birdwatching |
| `lab3` | Сайт аэропорта, вариант 14, с учебным бронированием |
| `lab4` | XML, DTD, XSD и таблица случайных RGB-цветов |
| `reports` | Отчёты `lab1.docx` – `lab4.docx` |
| `лабы метоидчки` | Методички и материалы заданий |
| `publish` | Фрагмент конфигурации Caddy и инструкция публикации |

Для локального просмотра откройте корневой `index.html` в браузере.
Установка зависимостей не требуется. Формы и сценарии работают в браузере.

Существующий Caddy расписания открывает файлы прямо из репозитория.
После коммита и пуша обновите сайт командой:

```sh
git -C /opt/web-labs/repo pull --ff-only
```

Сборка не нужна. Подробнее – в [инструкции публикации](publish/README.md).
