# Лабораторная работа 5

Вариант 14: форма бронирования авиабилета на сайте аэропорта.

Откройте `index.html`, затем ссылку «Открыть форму бронирования».
Сама новая страница находится в `../lab3/reservation.html` и добавлена в меню всех страниц сайта аэропорта. Примеры элементов HTML-форм находятся в `examples.html`.

Для проверки заполните обязательные поля, выберите рейс и дату не раньше сегодняшней, подтвердите данные и нажмите «Проверить заявку». Ниже появится результат. Кнопка «Очистить форму» возвращает исходные значения. Заявка обрабатывается локально в браузере и не создаёт настоящего бронирования.

Отчёт: `../лабы/lab5.docx`.

После загрузки на прежний сервер адрес формы: https://hki-stroitel.ru:8443/web-labs/lab3/reservation.html. Публикация ещё не выполнена.
