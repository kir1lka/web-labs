# Публикация лабораторных работ

Сайт: [Лабораторные работы](https://hki-stroitel.ru:8443/web-labs/).

Лабораторные раздаёт существующий Caddy расписания. Файл `publish/Caddyfile`
подключается через `import /repo/publish/Caddyfile` только внутри блока сайта
на порту `8443`. Репозиторий подключается в контейнер как `/repo` только для чтения.
Отдельный контейнер лабораторных не нужен.

Меню находится в корневых `index.html` и `styles.css`. Страницы лабораторных
расположены в `lab1`–`lab6`, отчёты – в `лабы`.
Caddy закрывает скрытые файлы, отчёты, методички и служебные файлы;
XML, DTD и XSD доступны для просмотра.

После коммита и пуша обновите файлы на сервере:

```sh
git -C /opt/web-labs/repo pull --ff-only
```

Для обновлений HTML, CSS, JavaScript и XML не нужны сборка, FTP или
перезагрузка Caddy. Обновите страницу в браузере. Первоначальная загрузка
по FTPS уже выполнена.

Для лабораторной работы 5 новая форма находится в `lab3/reservation.html`;
`lab5/index.html` содержит ссылку на неё и на примеры элементов форм.
Лабораторная работа 6 находится в `lab6/index.html`.
После публикации изменения самого `publish/Caddyfile` требуется штатная
проверка конфигурации и её перезагрузка в существующем Caddy.
