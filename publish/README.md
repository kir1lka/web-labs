# Публикация лабораторных работ

FTP с явным TLS также открывает эти же файлы лабораторных. После изменений по FTP
сохраните их и в репозитории перед следующим `git pull`, иначе Git может потребовать
согласовать локальные изменения. Папка FTP теперь содержит каталоги лабораторных из репозитория.

Сайт: [Лабораторные работы](https://hki-stroitel.ru:8443/web-labs/).

Caddy раздаёт файлы непосредственно из репозитория. Для обновления на сервере:

```sh
git -C /opt/web-labs/repo pull --ff-only
```

После изменения HTML, CSS, JavaScript или XML сборка и перезагрузка Caddy
не нужны. Обновите страницу в браузере. FTP для обновлений не используется;
первоначальное размещение по FTPS уже выполнено.

Меню хранится в `publish/menu`, подменю первой работы – в
`publish/lab1-index.html`. Файлы лабораторных находятся в своих исходных папках.

`publish/Caddyfile` предназначен для отдельного Docker-контейнера лабораторных.
Репозиторий подключается в `/repo` только для чтения, каталог сертификатов –
в `/certs` только для чтения. Порт контейнера `443` публикуется на порту `8443`.
Конфигурация основного приложения не изменяется.

Конфигурация сохраняет адреса `/web-labs/lab1/` – `/web-labs/lab4/`,
разрешает XML, DTD и XSD и закрывает служебные файлы и отчёты.
