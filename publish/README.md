# Публикация лабораторных работ

Сайт: [Лабораторные работы](https://hki-stroitel.ru:8443/web-labs/).

Из папки `web` запустите:

```powershell
python publish/build_site.py
```

Готовые файлы появятся в `_проверка/site`. Для другой папки:

```powershell
python publish/build_site.py --output C:/Temp/web-labs
```

Подключитесь к `hki-stroitel.ru`, порт `21`, протокол FTP с явным TLS
(Explicit FTPS), пассивный режим. Используйте отдельную учётную запись для лаб.
Загрузите содержимое папки сборки в каталог `/web-labs`.

Меню хранится в `publish/menu`, подменю первой работы – в
`publish/lab1-index.html`. Сборщик копирует текущие исходники лабораторных,
добавляет ссылки возврата и не включает отчёты и материалы проверки.
